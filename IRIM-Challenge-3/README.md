## Project Description

**Introduction to Incident Response and Management-3** is a web-based game developed using ReactJS. In this game, players take on the role of an investigator equipped with a magnifying glass, simulating the process of investigating incidents. Players need to navigate through challenges, avoiding hazards while collecting clues to earn points.

## Technologies Used

-  ReactJS (Frontend Library) (TS)
-  Tailwind CSS (CSS Framework)
-  Prime React (React UI Component Library)
-  Vite (Frontend Tooling)

## Installation

To run the game locally, follow these steps:

1. Clone the repository.
2. Install dependencies using Yarn: `yarn`
3. Start the development server: `yarn dev`

## Gameplay

Launch the game using the instructions provided above. As the investigator character moves forward, you can make them duck or jump to avoid obstacles and hazards. Collect randomly generated clues along the way to earn points.
The game is set up as an endless runner-style experience. Players control the investigator's movements to avoid obstacles by ducking or jumping. Obstacles and hazards spawn randomly, so stay alert! Clues also appear randomly, so try to collect as many as you can while avoiding hazards.

## Winning Criteria

To win the game, ensure that you keep your score above then zero for 1 minute.

## Scoring System

Players earn points by collecting clues in succession. The longer your streak of collecting clues without encountering hazards, the higher your score multiplier will be. However, if you hit a hazard, you'll lose your streak and some points. After one minute of gameplay, you can choose to end the investigation or continue for a higher score.
