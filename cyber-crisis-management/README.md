# Cyber Crisis Management

Welcome to **Cyber Crisis Management**, an interactive game developed using the ReactJS library of JavaScript. This game guides users through various rounds of the Incident Lifecycle, where they need to make strategic decisions within budget constraints.

## Project Description

**Cyber Crisis Management** is a web-based game built with ReactJS and TypeScript. Players progress through different phases of the Incident Lifecycle, making crucial decisions based on limited resources and budget.

## Technologies Used

-  ReactJS (Frontend Library) (TS)
-  Tailwind CSS (CSS Framework)
-  Prime React (React UI Component Library)
-  Vite (Frontend Tooling)

## Installation

To run the game locally, follow these steps:

1. Clone this repository.
2. Navigate to the project directory: `cd cyber-crisis-management`
3. Install dependencies using Yarn: `yarn`
4. Start the development server: `yarn dev`

## Usage

Launch the game using the instructions provided above. Engage with the game by making choices in each phase of the Incident Lifecycle. Manage your budget effectively to mitigate both estate and reputation damage.

## Gameplay

The game consists of four narratives, each with four phases. Players must carefully choose from a set of options in each phase, taking into account their budget constraints. The goal is to maintain estate and reputation damage at a level less than 50% to win.

## Winning Criteria

To win the game, ensure that both estate damage and reputation damage remain less then 50% throughout the gameplay. Your strategic decisions will determine the outcome!
